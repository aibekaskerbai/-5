«Грамотейка» — Образовательная платформа по русскому языку (5 класс)

Интерактивная EdTech-платформа с поддержкой ЖИ (Gemini Vision API & Gemini Flash API) для проверки рукописных диктантов, автоматического анализа ошибок и индивидуальной работы над пробелами учеников 5 класса.

🌟 Негізгі мүмкіндіктері (Основные возможности)

Мультимодальды талдау (OCR + AI):

Дәптер фотосынан қолжазба мәтінді тану (Gemini Vision).

Мәтінді оқып, орфографиялық және пунктуациялық қателерді анықтау.

«Было» — «Правильно» — «Правило» кестесін генерациялау.

Персональды тренажёрлар (Адаптивные упражнения):

Оқушының «Басты өсу нүктесіне» (жиі жіберетін қатесіне) негізделген 3 динамикалық жаттығу құрастыру.

🔊 «Говорим & Пишем» Аудио-модулі (60 слов):

5-сынып бағдарламасындағы айтылуы мен жазылуы әртүрлі 60 негізгі сөздің аудирование плейері (Web Speech API).

60 секундтық «Орфографический Детектив» және «Гласные в Корне» скоростные тренажёры.
